algoetl

An open-source Python exporter that turns any Algorand Indexer into date-partitioned Parquet for Athena, DuckDB or Spark. Algorand isn't in Dune's data catalog, so this fills a real gap. It's built to be submitted as an Algorand xGov retroactive grant.

Example data. The numbers below come from running the real pipeline over 60 synthetic blocks shaped like Indexer responses. The build workspace can't reach Algorand APIs, so the first mainnet run is a setup step.

Pipeline

Indexer /v2/blocks/{round}→transform (inner txns flattened)→Parquet · date=YYYY-MM-DD→S3 + Glue projection→Athena SQL

A Lambda runs every 5 minutes and catches up from a checkpoint to the chain tip at 4 req/s with 429 backoff. Re-runs are idempotent. Tests: 11 passing (transform, inner-txn ids, partitioning across midnight, resume, backoff, throttle, S3 keys).
